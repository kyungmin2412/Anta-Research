# Anta Research

금융감독원 전자공시(DART) 오픈API로 국내 법인의 재무·수익성·안정성을 살펴보는 기업분석 웹앱입니다. 화면은 토스 스타일을 참고했습니다.

## 무엇을 볼 수 있나요

- **기업 검색** — 이름·영문명·종목코드로 10만 개가 넘는 DART 등록 법인을 찾습니다.
- **핵심 지표** — 최근 기간의 매출액, 영업이익, 당기순이익, 자산총계와 직전 기간 대비 증감.
- **지표 차트** — 볼 지표를 골라 차트로 봅니다. 매출액·영업이익·당기순이익, 매출총이익률·영업이익률·순이익률·ROE·ROA, 자산·자본·부채비율·유동비율·재고자산·현금및현금성자산, 영업활동현금흐름·설비투자(CAPEX)·잉여현금흐름(FCF). 고른 목록은 URL에 담겨 그대로 공유됩니다.
- **기간 전환** — 연간 5개년 또는 분기 20개(약 5년치)를 화면 위 탭으로 바꿉니다.
- **증감률** — QoQ(직전 분기 대비)와 YoY(전년 동기 대비)를 따로 또는 함께 봅니다. 지표 카드에 배지로 붙고 차트에는 오른쪽 축에 겹쳐 그립니다. 비율 지표는 나눈 값이 아니라 뺀 값(%p)으로 내고, 적자 구간은 숫자 대신 흑자전환·적자전환으로 적습니다. 연간 보기에서는 직전 기간이 곧 전년이라 "전년 대비" 하나로 합칩니다.
- **재무 안정성** — 부채비율, 유동비율, 자기자본비율과 자본/부채 구성.
- **현금흐름** — 영업·투자·재무활동 현금흐름.
- **연결 vs 별도** — 같은 사업연도의 연결·별도 재무제표를 나란히 놓아 자회사가 실적에 보태는 몫을 봅니다.
- **기업 비교** — 최대 4곳까지 실적 추이와 재무비율을 나란히 비교합니다.
- **개별 기업 분석** — 기업 하나의 최근 5년 정기보고서(사업·반기·분기)를 회계연도별로 모아 보고 원문으로 건너뜁니다. 같은 기간에 정정신고가 여러 건이면 마지막 접수분만 남깁니다.
- **본문 지표** — 사업보고서 원문을 받아 본문 표에서 해외 매출 비중, 가동률, 제품 가격변동 추이, 수주잔고를 읽습니다. 재무제표 API에는 없는 값들입니다. 표가 없는 회사는 해당 카드를 내지 않습니다.

## 시작하기

1. [오픈DART](https://opendart.fss.or.kr/uss/umt/EgovMberInsertView.do)에서 인증키를 무료로 발급받습니다.
2. 프로젝트 루트에 `.env.local`을 만들고 키를 넣습니다.

   ```bash
   cp .env.example .env.local
   # DART_API_KEY=발급받은키
   ```

3. 의존성을 설치하고 개발 서버를 실행합니다.

   ```bash
   npm install
   npm run dev
   ```

4. http://localhost:3000 을 엽니다.

## 구조

| 경로 | 역할 |

| `app/page.tsx` | 검색 중심의 홈 화면 |
| `app/company/[corpCode]/page.tsx` | 기업분석 리포트 (서버 컴포넌트) |

| `lib/report-metrics.ts` | 본문 표에서 가동률·해외매출 등 뽑기 |
| `app/api/search/route.ts` | 기업명·종목코드 검색 엔드포인트 |
| `lib/dart.ts` | DART 오픈API 호출과 오류 코드 처리 |
| `lib/corp-code.ts` | 고유번호 목록 다운로드·캐싱·검색 |
| `lib/finance.ts` | 재무제표 계정 매핑과 비율 계산 |
| `components/FinancialCharts.tsx` | Recharts 기반 실적·수익성 차트 |

기업 고유번호 목록(`corpCode.xml`, 약 11만 건)은 `npm run build`가 미리 내려받아 `data/corp-index.tsv`로 만들어 둡니다. 서버 인스턴스가 새로 뜰 때마다 1.4MB를 다시 받지 않아도 되어, 첫 검색이 4초대에서 0.3초대로 줄어듭니다.

`DART_API_KEY` 없이 빌드하면 색인을 건너뛰고, 런타임이 예전처럼 DART에서 직접 받아 임시 디렉터리에 24시간 보관합니다. 색인은 빌드 시점 목록이라 그 뒤 새로 등록된 법인은 다음 배포 때 반영됩니다.

나머지 응답은 Next.js의 `revalidate`로 캐싱해 DART의 일일 호출 한도(20,000건)를 아낍니다.

## 주의

DART 오픈API는 정기보고서(사업보고서) 기준 데이터를 제공합니다. 시가총액·주가처럼 실시간 시장 데이터는 포함되지 않으며, 비상장 법인은 재무제표가 공시되지 않을 수 있습니다. 투자 판단의 책임은 이용자 본인에게 있습니다.

## 분기 값을 만드는 방법

DART는 분기 손익을 회사마다 다른 모양으로 싣는다. 세 가지가 섞여 있다.

1. 당기누적금액 칸에 누적, 당기금액 칸에 3개월치 (표준)
2. 당기누적금액 칸을 비우고 당기금액 칸에 누적만
3. 당기누적금액 칸을 비우고 당기금액 칸에 3개월치만

누적 칸이 있으면 그쪽을 먼저 읽는다(1번 처리). 없으면 당기금액을 읽는데, 이때
2번인지 3번인지는 값만 봐서는 알 수 없다. 매출은 기간이 길어질수록 줄어들 수
없다는 점을 쓴다. 뒤 분기 매출이 앞 분기보다 작으면 누적이 아니라고 보고 읽은
값을 3개월치로 그대로 쓴다. 이 판정은 회사·연도 단위로 따로 한다.

4분기는 어느 방식이든 사업보고서에 연간 총액이 실리므로, 3개월치를 싣는
회사라면 앞 세 분기를 빼서 만든다.

한계: 3번 방식이면서 그 해 분기 매출이 계속 늘어난 회사는 가려내지 못한다.
이 경우 4분기가 유난히 크게 나온다.

## 본문 지표를 읽는 방법

가동률, 제품 가격변동 추이, 해외 매출 비중, 수주잔고는 정형 API에 없고 정기보고서 본문 "II. 사업의 내용"의 표에만 있습니다. 그래서 `document.xml`로 공시서류 원본을 받아 직접 읽습니다.

원본은 이름만 xml이고 실제로는 ZIP입니다. 안에 본문 XML 한 개와 첨부 몇 개가 들어 있고 본문 파일 이름이 접수번호와 같습니다. 인코딩은 UTF-8, 표는 HTML과 같은 `TABLE`/`TR`/`TH`/`TD`에 `ROWSPAN`·`COLSPAN`을 씁니다. 목차는 `SECTION-1` 안의 `TITLE`로 나뉩니다. DART는 주석과 진짜 표를 한 칸짜리 표로 한 번 더 감싸는 일이 잦아 안쪽 표만 골라 읽습니다.

표를 찾을 때는 소제목이 아니라 **머리글 문구**를 봅니다. 소제목은 앞 문단과 섞여 들쭉날쭉하지만 머리글은 기업공시서식 작성기준을 따라 어느 회사나 비슷하기 때문입니다. 기간 칸은 칸 전체가 "제55기"나 "2023년"일 때만 인정합니다. 주석 문장 속 "2023년부터" 같은 말을 기간으로 세면 열이 통째로 밀립니다.

찾지 못한 지표는 비워 둡니다. 억지로 채우지 않습니다. 표 모양은 회사마다 다르지만 한 회사 안에서는 해마다 거의 같아서, 회사를 늘릴 때마다 매핑을 하나씩 더하는 쪽으로 넓힙니다.

**검증 범위**: 삼성전자 2023년 사업보고서 원문 한 건으로 확인했습니다. 가동률 5건, 지역별 매출 3개년, 제품 가격변동이 원문 표와 일치합니다. 다른 업종(건설·서비스업)으로는 아직 확인하지 못했습니다.

## DART로 담을 수 없는 지표

P/E, P/B, Forward P/E처럼 주가가 필요한 지표는 넣지 못했습니다. DART는 정기보고서의 재무제표만 제공하고 주가는 담고 있지 않습니다. 발행주식수와 EPS·BPS는 공시에서 얻을 수 있으므로, 주가만 다른 곳(한국거래소 등)에서 가져오면 계산할 수 있습니다. 애널리스트 추정이 필요한 Forward P/E는 DART 범위 밖입니다. 통화도 원화만 다룹니다.
